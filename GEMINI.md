# Everyday Software Voice Demo

Use `prepare_voice_demo_link` when a user asks to try a website-based AI receptionist.
Ask for a public business website if it is missing. Return the `demo_url` as a link.
The result is a prepared link, not a built or deployed phone agent. The user opens
it, selects Build My Demo, and then starts a browser microphone conversation.
Do not claim the source business endorses the demo. Do not promise bookings,
transfers, dispatch, outbound calls, or notifications to that business.
No sign-in or API key is required. Never ask for website account credentials.
